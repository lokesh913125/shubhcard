# 🪔 ShubhCard - Bio Data, Shadi Card & Shok Patra Maker

Free PDF maker app for Indian families. Create beautiful Bio-Data, Wedding Cards, Shok Patra (Condolence cards), and 12+ other documents in Hindi & English.

## ✨ Features

- 💍 **Marriage Bio-Data Maker** with photo, kundli details, family info
- 🪔 **Wedding Invitation Cards** with multiple templates
- 🕊️ **Shok Patra / Condolence Cards** with Tervi details
- 🎂 **Birthday, Anniversary, Mundan, Griha Pravesh** invitations
- 💼 **Visiting Cards & Resume/CV Maker**
- 🏆 **Certificates, Receipts & Affidavits**

## 🎨 Customization

- 7 color themes (Maroon, Royal, Blue, Green, Purple, Pink, Classic)
- 3 text sizes (Small, Medium, Large)
- Add/remove fields & sections
- Add custom fields (grandparents, property, etc.)
- Hindi / English / Both language support

## 📤 Export Options

- HD PDF Download
- JPG Image Download
- WhatsApp Direct Share
- Print directly from phone

## 💎 Premium Features (₹99/month)

- No ads
- Premium templates
- No watermark
- Cloud save & edit
- Priority support

## 🚀 Tech Stack

- Pure HTML/CSS/JavaScript (single file)
- No build tools required
- PWA support (Add to Home Screen)
- Works offline
- jsPDF + html2canvas for PDF generation
